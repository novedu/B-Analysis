B站数据导出器

把你自己的观看历史、关注、收藏和稍后再看，导成一个 JSON 文件。

这个插件做什么

会做的

  • 读取你自己的观看历史
  • 读取你的关注列表
  • 读取你的收藏夹与稍后再看
  • 在本地生成 JSON 或 CSV 文件

不会做的

  • 不会点赞、评论、关注
  • 不会修改你的任何数据
  • 不会上传到任何服务器
  • 不会读取 Cookie 内容

拿到的是什么

一个 JSON 文件，包含四个数组/object：

  • history — 观看记录：标题、UP 主、观看时间、视频时长、看到第几秒、分区
  • followings — 关注：UID、昵称、签名、认证、关注时间
  • favorites — 收藏夹：按夹子分组，含标题、UP 主、时长、发布时间
  • toview — 稍后再看：标题、UP 主、加入时间

也可以导出 CSV：四张独立表格，带 UTF-8 BOM，Excel 双击不乱码。

字段说明见项目 README 的「数据格式」一节。

三个必须知道的限制

  • 观看历史只有约 1200 条。B 站只保留这么多，按每天 20–30 条算大约是 40–50 天，更早的拿不到。
  • 关注列表单次接口只给 1000 条。本插件用正序 + 倒序双向抓取来补全，通常能拿全。
  • 点赞、投币、评论、弹幕、搜索历史都没有导出接口。不是本插件的问题，是平台不提供。

隐私

所有请求都在你的浏览器里直接发往 api.bilibili.com，复用你已有的登录态。插件不读取、不存储、不上传 Cookie，也没有任何后端服务器。

导出的文件保存在你选择的下载目录里。这个文件包含你的完整观看记录，请自行保管。
